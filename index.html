# About

I'm a Mobile Application Developer specializing in Android (Kotlin, Java) and Flutter (Dart). Over 5+ years I've delivered production-grade applications across fintech, B2B, e-commerce, and social platforms — for clients including Bangladesh Krishi Bank, Coca-Cola, Unilever, JTI, and Arla.

I build large-scale apps using MVVM and Clean Architecture, backed by Firebase, REST APIs, offline-first features, and native integrations — prioritizing scalability and performance. Along the way I've contributed to technical decisions, mentored teammates, and pushed development standards forward on every team I've joined.
